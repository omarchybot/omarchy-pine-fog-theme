# Pine Fog

![Pine Fog](preview.png)

A quiet forest morning: fog in the pines, moss underfoot, cold air and the first warm light through the trees.

## Install

```bash
omarchy theme install https://github.com/sumdahl/omarchy-pine-fog-theme
```
